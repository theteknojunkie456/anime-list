# WatchList — coding conventions (Aider loads this every session)

## The rule that matters most
This is a **single-file app**: the entire product is `index.html` — inline
`<style>`, one large inline `<script>`, then the HTML `<body>`. **A single JS
syntax error blanks the whole app** (no icons, no content). The `check-syntax`
lint runs automatically after every edit; never commit if it fails.

## How to edit
- Make **small, surgical, exact edits**. Never regenerate large blocks or use
  `sed`/`awk`/regex to rewrite the file — that has broken it every time.
- **New HTML goes in the `<body>`**, never inside `<script>` or a JS string.
- Multi-line strings must be template literals (backticks). IIFE syntax is
  `(()=>{ … })()` — call parens outside the arrow. `await` only works in `async`.
- `friends.html` is auto-generated by a pre-commit hook — never edit it by hand.
- After a change, **load the page and confirm it renders** before pushing.

## Design system (match it — do not invent)
- Colors are CSS custom properties, never hardcoded hex: surfaces `--bg`..`--bg5`,
  borders `--b1`..`--b3`, text `--t1`/`--t2`/`--t3`, accent `--a`/`--a2`, tint
  `--ag`, `--glow`, status `--wat`/`--pln`/`--fin`/`--drp`. `--a1` does NOT exist.
- Icons are inline Feather SVG via `icon('name', variant)`. **No emoji in the UI.**
- Fonts: Bricolage Grotesque (display, `--fd`, weight 800) + Manrope (body).
- The accent glow shadows are intentional brand — keep them.

## Data & structure
- One flat array `anime[]`; `kindOf(a)` → `'watch'` | `'read'`. Persist via `save()`.
- Metadata from AniList GraphQL (`graphql.anilist.co`) + Jikan. State lives in
  `localStorage` (key `animelist_v4`) plus optional cloud + AniList account sync.
- Backend: Cloudflare Workers in `cloud/` (auto-deploy on push to `cloud/**`).

## Deploy
- `git push origin main` → GitHub Pages goes live in ~1 min. A broken push is a
  broken live app — verify first.
- **Verify by reading the live build, not by the push succeeding.** `curl` the
  deployed `sw.js` and compare its `animelist-…` stamp to the local one. The
  stamp is derived from `index.html`, so an app change must move it and a docs
  or tooling change must not — which also tells you which kind of change you
  just shipped.
- **A Pages deploy that fails with "0 artifacts" must not be re-run with
  `gh run rerun --failed`.** That job uploads *and* deploys, so re-running it
  adds a second artifact named `github-pages` and the next error is "Multiple
  artifacts… count is 2" — a transient failure turned into a permanent one.
  Artifacts are scoped per run: start a fresh one with
  `gh workflow run deploy.yml --ref main` (no empty commit needed).

## Tests
- `sh scripts/suite.sh` runs every suite: `scripts/*-test.mjs`, `scripts/*.test.mjs`
  **and `cloud/*.test.mjs`**. It judges by **exit status**, and sweeps stray
  Chrome/http.server processes between files — a crashed test otherwise holds
  its port and takes every later test down with it.
- **A test outside the suite reports to nobody.** The `cloud/` files were run by
  hand, which means they were run when somebody remembered: two of them failed
  for a whole release against a worker that was correct, and nothing said so. If
  you add a test, it goes where the suite already looks.
- **Never assert after a fixed sleep.** Poll for the condition with a deadline.
  A flat `wait(1200)` passes on an idle machine and reports a false failure when
  forty browsers are running, and a suite that cries wolf stops being read.
  This applies to **positive** assertions — "this must have arrived". A
  **negative** one — "a guest CANNOT kick the host" — keeps its flat sleep on
  purpose: there is nothing to wait for, and waiting would only give the thing
  being forbidden more time to happen. Writing the rule down was not enough on
  its own: `party-live` carried it in a header comment while 42 of its 46
  assertions still slept and hoped.
- A test that writes a persisted setting must clear it first, or its second run
  starts where the first left off. Each test gets its own `--user-data-dir`.
- **Run one suite at a time, and nothing else that opens a browser.** The suite
  sweeps its own ports, but a second suite — or an `audit-visual` run started
  while one is going — collides and the damage reads as real test failures.
  `full-copy` and `sync-diagnose` both "failed" that way and both passed 20/20
  and 25/25 alone. A suite started immediately after another one can also hit a
  port the previous run has not released yet, which it reports honestly
  (`ports busy after sweep`, exit 2) and which is easy to misread as a pass.
  If a failure cannot be caused by your change, check what else was running
  before bisecting.
- **Never put anything after the command whose status you need.**
  `sh scripts/suite.sh > log 2>&1; echo "exit=$?"` exits 0 whatever the suite
  did, because the echo is the last command — and `make build | tail -5` reports
  tail's status, not the build's. Run it bare, or `set -o pipefail`. The suite
  judges by exit status and says so above; a wrapper that eats it turns every
  rule in this section into decoration. Read the `---- N ok, M failing` line as
  well, and once, make something fail ON PURPOSE and confirm the wrapper says
  so: a status channel nobody has seen carry a failure is not known to work.

## Don't
- Do NOT add in-app streaming from scraper/torrent sources (anikoto, consumet,
  megaplay, gogoanime, Torrentio…). It cannot work in a browser (CORS + Referer
  blocks) and it's copyright infringement. The supported "watch" path is the
  official **"Watch on ___"** links + **AniList sync**.
