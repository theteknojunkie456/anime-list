WatchList
For Android

Two ways to get it.

Both give you the same app with its own icon, full screen, working offline. The first takes about ten seconds.

Recommended

Install from Chrome

Nothing to download, and it updates itself every time we ship something.

  1. Open WatchList in Chrome.
  2. Tap Install app when Chrome offers it — or ⋮ menu → Add to Home screen.
  3. Open it from your home screen like any other app.
Open WatchList in Chrome

Notifications work on Android, so you'll get told when a new episode of anything you track drops.

App file

Download the APK

A normal installable app file, if you'd rather have one — to sideload, or to pass to someone directly.

  1. Download the latest watchlist.apk from Releases.
  2. Open it. Android will ask you to allow installing from your browser — that's normal for an app that isn't from the Play Store.
  3. Install, and it appears in your app drawer.
Get the latest release

Same app, wrapped. It still updates its contents automatically, so you won't need to reinstall for new features.

On an iPhone? Open the site in Safari and tap Share → Add to Home Screen.
