# WatchList — coding conventions (Aider loads this every session)

## The rule that matters most
This is a **single-file app**: the entire product is `index.html` — inline
`<style>`, one large inline `<script>`, then the HTML `<body>`. **A single JS
syntax error blanks the whole app** (no icons, no content). The `check-syntax`
lint runs automatically after every edit; never commit if it fails.

## How to edit
- Make **small, surgical, exact edits**. Never regenerate large blocks or use
  `sed`/`awk`/regex to rewrite the file — that has broken it every time.
- **New HTML goes in the `<body>`**, never inside `<script>` or a JS string.
- Multi-line strings must be template literals (backticks). IIFE syntax is
  `(()=>{ … })()` — call parens outside the arrow. `await` only works in `async`.
- `friends.html` is auto-generated by a pre-commit hook — never edit it by hand.
- After a change, **load the page and confirm it renders** before pushing.

## Design system (match it — do not invent)
- Colors are CSS custom properties, never hardcoded hex: surfaces `--bg`..`--bg5`,
  borders `--b1`..`--b3`, text `--t1`/`--t2`/`--t3`, accent `--a`/`--a2`, tint
  `--ag`, `--glow`, status `--wat`/`--pln`/`--fin`/`--drp`. `--a1` does NOT exist.
- Icons are inline Feather SVG via `icon('name', variant)`. **No emoji in the UI.**
- Fonts: Bricolage Grotesque (display, `--fd`, weight 800) + Manrope (body).
- The accent glow shadows are intentional brand — keep them.

## Data & structure
- One flat array `anime[]`; `kindOf(a)` → `'watch'` | `'read'`. Persist via `save()`.
- Metadata from AniList GraphQL (`graphql.anilist.co`) + Jikan. State lives in
  `localStorage` (key `animelist_v4`) plus optional cloud + AniList account sync.
- Backend: Cloudflare Workers in `cloud/` (auto-deploy on push to `cloud/**`).

## Deploy
- `git push origin main` → GitHub Pages goes live in ~1 min. A broken push is a
  broken live app — verify first.

## Don't
- Do NOT add in-app streaming from scraper/torrent sources (anikoto, consumet,
  megaplay, gogoanime, Torrentio…). It cannot work in a browser (CORS + Referer
  blocks) and it's copyright infringement. The supported "watch" path is the
  official **"Watch on ___"** links + **AniList sync**.
